## Brand & Style

The design system embodies a celestial abyss where deep-space networking meets oceanographic benthic depth. Engineered for high-velocity developer onboarding and competitive technical trivia, it projects high-focus immersion, technical precision, and an adventurous sense of descending into uncharted territory.

The aesthetic fuses **Modern Sci-Fi Cybernetics** with **Atmospheric Layering**:
- **Palette & Atmosphere:** Monolithic dark canvases grounded in near-black abyss navy and midnight purple, energized by high-chroma electric violet vectors, luminescent cyan data lines, and stellar amber achievement accents.
- **Tone & Mood:** Cerebral, focused, electric, and gamified. The interface avoids frivolous ornamentation or skeuomorphic clutter in favor of crisp luminous boundaries, glowing volumetric borders, and telemetry-grade typography.
- **Audience Resonance:** Engineered specifically for software engineers, systems architects, and network developers who value terminal-clean data hierarchy, monospace metric tracking, and low-latency competitive feedback.

## Colors

The color system operates exclusively in dark mode, reflecting the transition through atmospheric and oceanic tiers.

- **Primary (`#704DE2` - Electric Violet):** Drives primary kinetic affordances, full-bleed action triggers, and primary telemetry frames.
- **Secondary (`#74DDF4` - Glowing Cyan):** Reserved for technical precision indicators, focus rings, link interactions, and countdown chronometers.
- **Tertiary (`#B6A4FF` - Soft Lavender):** Used for micro-copy highlights, badge foregrounds, and hovering intermediate states.
- **Neutral Base (`#080B24` - Deep Navy):** The structural canvas background providing infinity contrast. Paired with `surface-midnight` (`#17133B`) for containers and modal surfaces.
- **Zone Progression Scale:** A calibrated dynamic chromatic scale representing descending depth levels:
  - Surface: `#38BDF8` (Sky)
  - Twilight: `#60A5FA` (Blue)
  - Midnight: `#818CF8` (Indigo)
  - Silent Engine: `#A78BFA` (Purple)
  - Trench Code: `#D946EF` (Fuchsia)
  - Abyss Rose: `#FB7185` (Rose)
- **Gamification Gold (`#F4B844`):** Strictly reserved for streaks, rare distribution metrics, podium placement, and host credentials.

## Typography

The typographic hierarchy uses a triad structure:
1. **Geometric Futuristic Display (`Space Grotesk`):** Chosen for all brand headers, section titles, and modal banners. Rendered with uppercase styling and expanded tracking (`0.03em` to `0.06em`) to establish an advanced technical presence.
2. **Neutral Functional Interface (`Inter`):** Drives questions, answers, explanatory tooltips, and standard interactions. Tuned for dense legibility under high-contrast dark environments.
3. **Telemetry & Code Monospace (`JetBrains Mono`):** Handles all game mechanics requiring zero horizontal jitter: countdown timers, room codes, live depth metrics, frequency counts, and leaderboards.

All uppercase label classifications utilize `label-caps` with strict `0.1em` letter-spacing to delineate metadata headers from operational text.

## Layout & Spacing

The structural layout relies on an 8-point base module within a 12-column responsive fluid grid, bounded by a strict maximum container width of `1280px`.

### Responsive Breakpoints
- **Desktop (≥ 1024px):** 12-column layout. Margin `2rem` (`32px`), Gutters `1.5rem` (`24px`). Multi-column split layouts:
  - Daily Dive: 60% Question Workspace / 40% Depth Telemetry Gauge.
  - Battle Game: 40% Synchronized Question / 35% Frequency Distribution / 25% Live Leaderboard.
- **Tablet (768px – 1023px):** 8-column layout. Margin `1.5rem` (`24px`), Gutters `1rem` (`16px`). The battle game reflows into a 2-column stacked configuration, moving the leaderboard below telemetry metrics.
- **Mobile (< 768px):** 4-column layout. Margin `1rem` (`16px`), Gutters `1rem` (`16px`). Layout switches to a single column linear stack:
  - Depth meter condenses to a horizontal progress tracker across the card head.
  - Navigation links collapse to a streamlined header bar.
  - Answer frequency bars stack directly below the active prompt.

## Elevation & Depth

Visual hierarchy uses **Luminescent Depth Framing** rather than drop shadows. Because ambient black canvases swallow traditional dark drop shadows, elevation is communicated through border illumination, optical stacking, and localized colored radiation.

1. **Base Tier (Canvas):** Pure `#080B24`. Flat, non-interactive deep space surface with optional static micro-point dust textures.
2. **Container Tier (Cards & Panels):** Raised to `#17133B` with an omnipresent structural border: `1px solid rgba(112, 77, 226, 0.2)`. No dropshadows are applied under neutral states to preserve crisp boundary clarity.
3. **Elevated & Interactive Tier (Buttons, Hover Cards, Modals):**
   - Active interactive states project a violet back-glow: `box-shadow: 0 0 20px rgba(112, 77, 226, 0.25)`.
   - Highest-order alerts and focus rings swap to a cold cyan aura: `box-shadow: 0 0 16px rgba(116, 221, 244, 0.35)`.
4. **Overlay Tier (Results, Transition Sheets):** Utilizes `rgba(8, 11, 36, 0.88)` with a `16px` backdrop filter blur (`backdrop-blur-md`), bordered by continuous `1px rgba(112, 77, 226, 0.3)`.

## Shapes

The interface balances sharp cybernetic angles with ergonomic touch points:
- **Default Elements (`roundedness: 2`):** Primary inputs, action buttons, and player cards take `0.5rem` (`8px`) border radius, preserving clean linear alignment.
- **Large Structural Containers (`rounded-lg`):** Main gameplay cards, telemetry sidebars, and result dialogs feature `0.75rem` to `1rem` (`12px` to `16px`) corners.
- **Pills & Data Badges:** Status pills, rarity indicators, and room code counters are fully rounded (`9999px`) to immediately distinguish scalar metadata from actionable rectangular buttons.
